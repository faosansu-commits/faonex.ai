## 1.1 FAONEX.AI คืออะไร

FAONEX.AI เป็นเว็บแอปพลิเคชัน **AI Chatbot สำหรับใช้งานภายในองค์กร** จุดเด่นที่สำคัญที่สุดคือ:

- **รันโมเดล AI ในเครื่องของตัวเอง 100%** ผ่านซอฟต์แวร์ชื่อ [Ollama](https://ollama.com) — ไม่ต้องสมัคร ไม่ต้องจ่ายค่า API รายเดือนให้บริษัทภายนอก (เช่น OpenAI, Google) และข้อมูลการสนทนาไม่ออกจากเซิร์ฟเวอร์ขององค์กรเลย
- **รองรับผู้ใช้งานจำนวนมาก** (ออกแบบไว้รองรับได้ถึงระดับ ~2,000 คน) ด้วยฐานข้อมูล MySQL/MariaDB
- **มีแผงควบคุมแอดมินครบวงจร** จัดการผู้ใช้งาน โควตาการใช้งาน สถิติ และความปลอดภัยได้ในที่เดียว
- **มีระบบ "ความรู้ AI" เฉพาะทาง** ให้แอดมินกำหนดได้ว่าคำถามเรื่องใดต้องตอบจากข้อมูลที่กำหนดไว้เท่านั้น (เช่น ระเบียบการสมัครเรียน) กันไม่ให้ AI ตอบมั่ว

## 1.2 ส่วนประกอบของระบบ (Services)

ระบบทั้งหมดรันด้วย **Docker Compose** แบ่งเป็น 6 ส่วนที่ทำงานร่วมกัน:

| ส่วนประกอบ | หน้าที่ | เข้าถึงได้ที่ |
|---|---|---|
| **web** | เว็บหน้าบ้าน (Frontend) ที่ผู้ใช้งานเห็นและโต้ตอบด้วย | `http://<เซิร์ฟเวอร์>:8095` |
| **backend** | เซิร์ฟเวอร์ประมวลผล (API) เชื่อมต่อฐานข้อมูลและ AI | ใช้งานผ่าน `web` เท่านั้น |
| **ollama** | เครื่องมือรันโมเดลภาษา AI ในเครื่อง | ใช้งานผ่าน `backend` เท่านั้น |
| **mysql** | ฐานข้อมูลเก็บผู้ใช้งาน/ประวัติแชท/สถิติ | ใช้งานผ่าน `backend`/`phpmyadmin` |
| **phpmyadmin** | หน้าเว็บจัดการฐานข้อมูลสำหรับแอดมิน | `http://<เซิร์ฟเวอร์>:8096` |
| **ollama-init** | ตัวช่วยดาวน์โหลดโมเดล AI ให้อัตโนมัติตอนติดตั้งครั้งแรก | ทำงานครั้งเดียวแล้วปิดตัวเอง |

> **หมายเหตุ**: ผู้ใช้งานทั่วไปและแอดมินจะเข้าใช้งานผ่าน **พอร์ต 8095** เท่านั้น ส่วนพอร์ต 8096 (phpMyAdmin) มีไว้ให้เฉพาะแอดมินที่ต้องการดูแลฐานข้อมูลโดยตรง

## 1.3 เทคโนโลยีที่ใช้ (Tech Stack)

| ชั้น (Layer) | เทคโนโลยี | เหตุผลที่เลือกใช้ |
|---|---|---|
| Frontend | SvelteKit + Tailwind CSS | เบา เร็ว ปรับแต่งหน้าตาได้ง่าย |
| Backend | PHP 8.3 (Apache) | ติดตั้งง่าย เสถียร ไม่ต้องพึ่งพา runtime ซับซ้อน |
| ฐานข้อมูล | MySQL/MariaDB | รองรับผู้ใช้พร้อมกันจำนวนมาก มีเครื่องมือจัดการ (phpMyAdmin) |
| AI Engine | Ollama (Llama 3.2, Qwen 2.5, Gemma 2, Mistral, LLaVA) | โอเพนซอร์ส ฟรี รันบนเครื่องได้จริงแม้ไม่มี GPU |
| Container | Docker Compose | ติดตั้ง/ย้ายเครื่อง/อัปเดตระบบทำได้ในคำสั่งเดียว |

## 1.4 ฟีเจอร์หลักโดยสรุป

- **หน้าแชท**: พิมพ์หรือพูดคำถาม, แนบรูปภาพ/ไฟล์เอกสาร, สลับโหมด "แชททั่วไป" / "เขียนโค้ด", เลือกโมเดล AI ได้หลายค่าย, คำตอบแสดงผลแบบ streaming ทีละคำทันที
- **ระบบสมาชิก**: สมัคร/เข้าสู่ระบบด้วย username-password, บัญชีแรกที่สมัครเป็นแอดมินอัตโนมัติ
- **แผงควบคุมแอดมิน**: จัดการผู้ใช้งาน, แดชบอร์ดสถิติ, มอนิเตอร์ฮาร์ดแวร์, ตั้งค่าธีม/ภาษา, ระบบ API สำหรับเซิร์ฟเวอร์ภายนอก
- **ระบบความรู้ AI (RAG + Rule)**: กำหนดหัวข้อพร้อมคำค้น เมื่อคำถามตรงหัวข้อ AI จะตอบจากเอกสาร/คำตอบที่กำหนดไว้เท่านั้น

## 1.5 แผนภาพการทำงานคร่าวๆ

```
ผู้ใช้งาน (เบราว์เซอร์)
        │
        ▼
   [web:8095]  ← SvelteKit (หน้าเว็บ)
        │  ส่งคำขอ /api/*
        ▼
   [backend]   ← PHP API (ตรวจสิทธิ์, ตรรกะระบบ)
     │      │
     ▼      ▼
 [mysql]  [ollama]  ← ฐานข้อมูล และ เครื่องมือรันโมเดล AI
```

เมื่อผู้ใช้พิมพ์คำถามในหน้าแชท คำขอจะถูกส่งจาก `web` ไปยัง `backend` เพื่อตรวจสอบสิทธิ์และโควตาการใช้งานก่อน จากนั้น `backend` จะส่งคำถามต่อไปยัง `ollama` เพื่อประมวลผล แล้วส่งคำตอบกลับมาแบบ streaming ให้ผู้ใช้เห็นทีละคำ พร้อมบันทึกประวัติการสนทนาลง `mysql`
