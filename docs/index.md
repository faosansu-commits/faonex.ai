## FAONEX.AI คืออะไร

**FAONEX.AI** คือเว็บแอปพลิเคชัน AI Chatbot สำหรับใช้งานภายในองค์กร รันโมเดลภาษา AI ในเครื่องของตัวเองทั้งหมด (ผ่าน [Ollama](https://ollama.com)) โดย**ไม่ต้องพึ่งพา API key จากภายนอกหรือเสียค่าใช้จ่ายรายเดือน** ข้อมูลทุกอย่างอยู่ในเซิร์ฟเวอร์ขององค์กรเอง เหมาะสำหรับโรงเรียน หน่วยงาน หรือองค์กรที่ต้องการความเป็นส่วนตัวของข้อมูลและควบคุมต้นทุนได้เต็มที่

ระบบประกอบด้วย: หน้าแชทสำหรับผู้ใช้งานทั่วไป, แผงควบคุมสำหรับแอดมิน (จัดการผู้ใช้/สถิติ/ตั้งค่า), และระบบ "ความรู้ AI" ที่ให้แอดมินกำหนดคำตอบเฉพาะทางสำหรับคำถามที่พบบ่อยได้เอง

## ตำรานี้เหมาะกับใคร

- ผู้ดูแลระบบ (แอดมิน) ที่ต้องการติดตั้งและดูแลระบบ FAONEX.AI
- ครู/บุคลากรที่ได้รับสิทธิ์แอดมินให้จัดการเนื้อหาความรู้ AI หรือผู้ใช้งาน
- ผู้ใช้งานทั่วไปที่ต้องการเรียนรู้การใช้ฟีเจอร์ต่างๆ ของหน้าแชทให้เต็มประสิทธิภาพ
- นักพัฒนาที่สนใจโครงสร้างและสถาปัตยกรรมของระบบ

## วิธีใช้ตำรานี้

ตำราเล่มนี้ออกแบบให้**อ่านตามลำดับบทตั้งแต่ 1 ถึง 20** เพราะแต่ละบทต่อยอดจากบทก่อนหน้า โดยเฉพาะบทที่ 2-6 ที่เป็นการติดตั้งพื้นฐานที่ต้องทำให้เสร็จก่อนจึงจะไปต่อบทอื่นได้ ส่วนบทที่ 12 เป็นต้นไปสามารถข้ามไปอ่านเฉพาะหัวข้อที่สนใจได้หากติดตั้งระบบเสร็จแล้ว

ทุกบทมีขั้นตอนแบบเลขลำดับ (1, 2, 3, ...) ที่ทำตามได้ทีละขั้น พร้อมคำสั่งที่คัดลอกไปวางรันได้ทันที และตารางสรุปในจุดที่ซับซ้อน
