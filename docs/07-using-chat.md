## 7.1 หน้าตาของหน้าแชท

หน้าแชทออกแบบในสไตล์คล้าย ChatGPT แบ่งเป็น 2 ส่วนหลัก:

- **แถบด้านข้าง (Sidebar)**: ปุ่ม "แชทใหม่", ช่องค้นหาแชท, รายการประวัติการสนทนา, สรุปโควตาการใช้งานวันนี้
- **พื้นที่แชท**: เมื่อยังไม่มีข้อความ ช่องพิมพ์จะอยู่กึ่งกลางจอ พอเริ่มสนทนาแล้วช่องพิมพ์จะย้ายลงมาด้านล่างจอ

## 7.2 เริ่มแชทใหม่

1. กดปุ่ม **✎ แชทใหม่** ที่ด้านบนของแถบข้าง
2. พิมพ์คำถามในช่องกลางจอ แล้วกด `Enter` หรือปุ่ม **ส่ง** (กด `Shift+Enter` เพื่อขึ้นบรรทัดใหม่โดยไม่ส่ง)
3. คำตอบจาก AI จะแสดงผลแบบ**ทยอยพิมพ์ทีละคำ** (streaming) ทันที ไม่ต้องรอคำตอบเต็มก่อน

## 7.3 เปิด/ปิดแถบด้านข้าง

กดไอคอน **☰** ที่มุมซ้ายบนเพื่อเปิด/ปิดแถบด้านข้าง — มีประโยชน์เมื่อต้องการพื้นที่หน้าจอเต็มสำหรับอ่านคำตอบยาวๆ

## 7.4 ค้นหาประวัติแชทเก่า

พิมพ์คำค้นในช่อง **🔍 ค้นหาแชท** ที่แถบด้านข้าง ระบบจะกรองรายการสนทนาที่มีชื่อตรงกับคำค้นให้ทันที

## 7.5 ดูและลบประวัติแชท

- คลิกที่ชื่อแชทในแถบด้านข้างเพื่อเปิดดูประวัติการสนทนานั้น
- วางเมาส์เหนือรายการแชทแล้วกดไอคอน **🗑** เพื่อลบ (ระบบจะถามยืนยันก่อนลบเสมอ)
- ประวัติแชททุกรายการถูก**บันทึกถาวรลงฐานข้อมูลทันที** ไม่มีการหายไปเองแม้ปิดเบราว์เซอร์หรือรีสตาร์ทเซิร์ฟเวอร์

## 7.6 พิมพ์ด้วยเสียง (Speech-to-Text)

กดไอคอน **🎤** ข้างช่องพิมพ์ แล้วพูดคำถามได้เลย ข้อความจะถูกแปลงเป็นตัวอักษรใส่ในช่องพิมพ์อัตโนมัติ

{: .note }
> ฟีเจอร์นี้ใช้ Web Speech API ของเบราว์เซอร์เอง ทำงานได้ดีที่สุดบน **Google Chrome** และ **Microsoft Edge** หากเบราว์เซอร์ไม่รองรับ ปุ่มนี้จะไม่แสดงขึ้นมาให้เห็น

## 7.7 ให้ AI อ่านคำตอบออกเสียง

- **ทีละข้อความ**: วางเมาส์เหนือคำตอบของ AI แล้วกดปุ่ม **🔊 อ่านออกเสียง** ที่ปรากฏขึ้น
- **อัตโนมัติทุกคำตอบ**: กดไอคอน 🔊 ที่แถบด้านบนของหน้าเว็บ (header) เพื่อเปิดโหมดอ่านออกเสียงอัตโนมัติ ระบบจะอ่านคำตอบทุกข้อความให้ทันทีที่ตอบเสร็จ

## 7.8 หยุด AI ระหว่างกำลังตอบ

ขณะ AI กำลังพิมพ์คำตอบ ปุ่มส่งข้อความจะเปลี่ยนเป็นปุ่ม **⏹ หยุดตอบ** สีแดง กดเพื่อหยุดได้ทันที คำตอบส่วนที่พิมพ์ไปแล้วจะถูกเก็บไว้ในประวัติ ไม่หายไปไหน (รายละเอียดในบทที่ 11)

## 7.9 สลับธีมมืด/สว่าง และภาษา

กดไอคอน **⚙️ ตั้งค่า** ที่แถบด้านบน เลือกได้ทั้ง:

- **ธีม**: มืด (Dark) / สว่าง (Light)
- **ภาษา**: ไทย / อังกฤษ

ค่าที่เลือกจะถูกจำไว้ในเบราว์เซอร์ ไม่ต้องตั้งใหม่ทุกครั้งที่เข้าใช้งาน

## 7.10 ดูโควตาการใช้งานของตัวเอง

แถบด้านล่างของ Sidebar แสดงจำนวนครั้งและจำนวน token ที่ใช้ไปแล้ว**วันนี้** เทียบกับลิมิตที่แอดมินตั้งไว้ พร้อมแถบสีที่เปลี่ยนตามเปอร์เซ็นต์การใช้งาน (เขียว → เหลือง → แดงเมื่อใกล้เต็มโควตา)
