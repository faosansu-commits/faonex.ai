## 9.1 สลับไปโหมดเขียนโค้ด

ที่แถบด้านบนของหน้าแชท มีปุ่มสลับโหมด 2 แบบ:

- **แชททั่วไป** — ใช้โมเดล AI ทั่วไป เหมาะกับคำถามทั่วไป
- **เขียนโค้ด** — สลับไปใช้โมเดล AI ที่เชี่ยวชาญด้านการเขียนโปรแกรมโดยเฉพาะ (ค่าเริ่มต้นคือ `qwen2.5-coder`)

กดปุ่ม **เขียนโค้ด** เพื่อสลับโหมด ช่องพิมพ์ข้อความจะเปลี่ยนข้อความชี้แนะเป็น "อธิบายโค้ดที่ต้องการให้เขียน..." ทันที

## 9.2 ตัวอย่างการใช้งาน

พิมพ์คำขอ เช่น:

```
เขียนฟังก์ชัน Python สำหรับเรียงลำดับตัวเลขจากน้อยไปมาก
```

AI จะตอบกลับพร้อมโค้ดที่จัดรูปแบบเป็น **code block** อัตโนมัติ แยกจากข้อความอธิบายอย่างชัดเจน

## 9.3 การอ่านและคัดลอกโค้ด

แต่ละ code block จะมี:

- **แถบชื่อภาษา** ที่มุมบน (เช่น `python`, `javascript`)
- **ปุ่มคัดลอก** ที่มุมขวาบนของ code block — กดครั้งเดียวคัดลอกโค้ดทั้งหมดไปยัง clipboard ทันที ไม่ต้องลากเลือกเอง

## 9.4 ข้อจำกัดของโหมดเขียนโค้ด

- โหมดนี้**ไม่รองรับการแนบรูปภาพ** (ถ้าแนบรูป ระบบจะสลับไปใช้โมเดล vision โดยอัตโนมัติแทน ไม่ว่าจะเลือกโหมดใดอยู่ก็ตาม)
- คุณภาพของโค้ดขึ้นอยู่กับขนาดโมเดลที่ใช้ — โมเดลเริ่มต้น (`qwen2.5-coder:3b`) เป็นรุ่นเล็กเน้นความเร็วบน CPU เหมาะกับงานเขียนโค้ดพื้นฐานถึงปานกลาง หากต้องการความแม่นยำสูงขึ้นสำหรับงานซับซ้อน ผู้ดูแลระบบสามารถเปลี่ยนไปใช้รุ่นใหญ่กว่าได้ (ดูบทที่ 10) แต่จะตอบช้าลงมากหากเครื่องไม่มี GPU
