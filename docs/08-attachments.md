## 8.1 ปุ่มแนบไฟล์ (➕)

ที่ช่องพิมพ์ข้อความ กดปุ่ม **➕** จะเปิดเมนูตัวเลือก:

| ตัวเลือก | สถานะ | คำอธิบาย |
|---|---|---|
| 📎 แนบไฟล์/รูปภาพ | ✅ ใช้งานได้ | เลือกไฟล์รูปภาพหรือไฟล์ข้อความจากเครื่อง |
| 🌐 ค้นหาเว็บ | 🔜 เร็วๆ นี้ | ต้องเชื่อมต่อบริการค้นหาภายนอก (ยังไม่เปิดใช้งาน) |
| 🔎 ค้นหาเชิงลึก | 🔜 เร็วๆ นี้ | เช่นเดียวกับด้านบน |
| 🐙 เชื่อมต่อ GitHub | 🔜 เร็วๆ นี้ | ฟีเจอร์ในอนาคต |
| 🎨 เชื่อมต่อ Canva | 🔜 เร็วๆ นี้ | ฟีเจอร์ในอนาคต |

{: .note }
> ตัวเลือกที่ขึ้น "เร็วๆ นี้" ยังใช้งานไม่ได้จริง เนื่องจากต้องเชื่อมต่อบริการภายนอกที่มีค่าใช้จ่าย ซึ่งขัดกับหลักการออกแบบเดิมของระบบที่ตั้งใจให้รันได้โดยไม่ต้องพึ่งพา API ภายนอกเลย

## 8.2 แนบรูปภาพให้ AI ช่วยดู/อธิบาย

1. กดปุ่ม **➕ → 📎 แนบไฟล์/รูปภาพ**
2. เลือกไฟล์รูปภาพ (ขนาดไม่เกิน **4 MB**)
3. ระบบจะดาวน์โหลดโมเดลสำหรับดูรูปภาพ (vision model) อัตโนมัติหากยังไม่เคยใช้งานมาก่อน — จะขึ้นข้อความ "กำลังเตรียมโมเดลสำหรับดูรูปภาพ..." สักครู่
4. พิมพ์คำถามเกี่ยวกับรูป (หรือเว้นว่างไว้ ระบบจะถามให้อัตโนมัติว่า "อธิบายสิ่งที่เห็นในภาพนี้")
5. กดส่ง — AI จะตอบโดยอ้างอิงจากสิ่งที่เห็นในภาพ

{: .warning }
> รูปภาพที่แนบจะ**ไม่ถูกเก็บไว้ในประวัติแชท** เพื่อประหยัดพื้นที่ฐานข้อมูล ประวัติจะแสดงแค่ข้อความคำถามพร้อมสัญลักษณ์ `[แนบรูปภาพ]` แทน

## 8.3 แนบไฟล์ข้อความให้ AI อ่านประกอบคำตอบ

1. กดปุ่ม **➕ → 📎 แนบไฟล์/รูปภาพ**
2. เลือกไฟล์นามสกุล `.txt`, `.md`, หรือ `.csv`
3. เนื้อหาไฟล์จะถูกอ่านและใส่เป็นบริบทให้ AI ใช้ตอบคำถามโดยอัตโนมัติ
4. พิมพ์คำถามเกี่ยวกับเนื้อหาในไฟล์ แล้วกดส่ง

{: .note }
> ถ้าไฟล์มีเนื้อหายาวเกิน 20,000 ตัวอักษร ระบบจะตัดส่วนท้ายออกและระบุว่า "เนื้อหาถูกตัดเนื่องจากยาวเกินไป"

## 8.4 ลบไฟล์/รูปที่แนบไว้ก่อนส่ง

หากแนบไฟล์ผิดหรือเปลี่ยนใจ กดปุ่ม **✕** ที่มุมของการ์ดตัวอย่างไฟล์แนบ (แสดงอยู่เหนือช่องพิมพ์) เพื่อเอาออกก่อนกดส่ง

## 8.5 ประเภทไฟล์ที่ยังไม่รองรับ

| ประเภทไฟล์ | สถานะ | หมายเหตุ |
|---|---|---|
| PDF / Word (ให้ AI **อ่าน** ในหน้าแชท) | ❌ ยังไม่รองรับในหน้าแชทของผู้ใช้ทั่วไป | *แต่*แอดมินอัปโหลด PDF เข้าระบบความรู้ AI ได้ (บทที่ 17) |
| ไฟล์เสียง (แปลงเป็นข้อความ) | ❌ ไม่รองรับ | ต้องใช้บริการ Whisper แยกต่างหาก |
| วิดีโอ | ❌ ไม่รองรับ | Ollama ยังไม่มีโมเดลเข้าใจวิดีโอ |
| สร้างภาพ/วิดีโอใหม่ | ❌ ไม่รองรับ | ต้องใช้บริการแยก เช่น Stable Diffusion |
