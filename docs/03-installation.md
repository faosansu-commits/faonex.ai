## 3.1 ขั้นตอนที่ 1: ดาวน์โหลดโค้ด

**วิธีที่ 1 — ใช้ Git (แนะนำ)**

```bash
git clone https://github.com/faosansu-commits/faonex.ai.git
cd faonex.ai
```

**วิธีที่ 2 — ดาวน์โหลด ZIP**

1. เข้า [https://github.com/faosansu-commits/faonex.ai](https://github.com/faosansu-commits/faonex.ai)
2. กดปุ่มสีเขียว **Code** → **Download ZIP**
3. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ
4. เปิด Terminal แล้ว `cd` เข้าไปในโฟลเดอร์ที่แตกไฟล์

## 3.2 ขั้นตอนที่ 2: ตรวจสอบไฟล์ตั้งค่า `.env`

โปรเจกต์มีไฟล์ `.env` มาให้พร้อมค่าเริ่มต้นที่ใช้งานได้ทันที ไม่ต้องแก้อะไรก็รันได้เลย (รายละเอียดค่าทั้งหมดอธิบายในบทที่ 5) แต่ **แนะนำให้เปิดดูและแก้รหัสผ่านฐานข้อมูลก่อนใช้งานจริง**:

```bash
# เปิดไฟล์ .env ด้วยโปรแกรมแก้ไขข้อความใดก็ได้ เช่น
notepad .env          # Windows
nano .env             # macOS/Linux
```

มองหาบรรทัดเหล่านี้แล้วเปลี่ยนรหัสผ่านให้เป็นของตัวเอง:

```env
DB_PASSWORD=faonex_change_me
DB_ROOT_PASSWORD=faonex_root_change_me
```

## 3.3 ขั้นตอนที่ 3: สั่งรันระบบ

รันคำสั่งเดียวนี้จากโฟลเดอร์โปรเจกต์:

```bash
docker compose up -d --build
```

คำสั่งนี้จะทำงานตามลำดับอัตโนมัติ:

1. ดาวน์โหลด image พื้นฐานที่จำเป็น (PHP, MariaDB, Ollama, phpMyAdmin, Nginx)
2. สร้าง (build) ส่วน backend และ frontend ของ FAONEX.AI เอง
3. เริ่มฐานข้อมูล MySQL/MariaDB และรอจนพร้อม
4. เริ่ม Ollama แล้วดาวน์โหลดโมเดล AI เริ่มต้น 2 ตัว (แชททั่วไป + เขียนโค้ด) อัตโนมัติ
5. เริ่ม backend และ web

{: .important }
> ขั้นตอนดาวน์โหลดโมเดล AI ครั้งแรก (ข้อ 4) ใช้เวลาสักครู่เพราะไฟล์โมเดลมีขนาดหลาย GB ขึ้นกับความเร็วอินเทอร์เน็ต — เป็นเรื่องปกติ ไม่ใช่อาการค้าง

## 3.4 ขั้นตอนที่ 4: ติดตามความคืบหน้าการดาวน์โหลดโมเดล

เปิดดูสถานะการดาวน์โหลดโมเดลได้ด้วยคำสั่ง:

```bash
docker compose logs -f ollama-init
```

รอจนเห็นข้อความจบการทำงาน (กด `Ctrl+C` เพื่อออกจากการดูล็อกได้ ไม่กระทบการทำงานเบื้องหลัง)

## 3.5 ขั้นตอนที่ 5: ตรวจสอบว่าระบบพร้อมใช้งาน

```bash
docker compose ps
```

ควรเห็นบริการทั้งหมดมีสถานะ `Up` หรือ `Up (healthy)` ดังนี้:

```
NAME                     SERVICE       STATUS
ai-chatbot-backend       backend       Up
ai-chatbot-mysql         mysql         Up (healthy)
ai-chatbot-ollama        ollama        Up
ai-chatbot-phpmyadmin    phpmyadmin    Up
ai-chatbot-web           web           Up
```

(บริการ `ollama-init` จะมีสถานะ `Exited (0)` หลังทำงานเสร็จ — ถือว่าปกติ ไม่ใช่ข้อผิดพลาด)

## 3.6 ขั้นตอนที่ 6: เปิดใช้งานผ่านเบราว์เซอร์

เปิดเบราว์เซอร์ไปที่:

```
http://localhost:8095
```

(ถ้าติดตั้งบนเซิร์ฟเวอร์เครื่องอื่น ให้ใช้ IP ของเครื่องนั้นแทน `localhost` เช่น `http://192.168.1.50:8095`)

ระบบจะพาไปหน้า **สมัครสมาชิก** เนื่องจากยังไม่มีบัญชีในระบบเลย — สมัครบัญชีแรกได้ทันที (รายละเอียดวิธีสมัครและสิทธิ์แอดมินอธิบายในบทที่ 6)

## 3.7 คำสั่งพื้นฐานที่ควรรู้

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `docker compose up -d` | เริ่มระบบ (ถ้าเคย build แล้วไม่ต้องใส่ `--build` ซ้ำ) |
| `docker compose down` | หยุดระบบทั้งหมด (ข้อมูลยังอยู่ครบ) |
| `docker compose ps` | ดูสถานะบริการทั้งหมด |
| `docker compose logs -f backend` | ดูล็อกของ backend แบบเรียลไทม์ |
| `docker compose restart backend` | รีสตาร์ทเฉพาะ backend |
