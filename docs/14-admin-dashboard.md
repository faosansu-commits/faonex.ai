## 14.1 เข้าดูแดชบอร์ด

ไปที่ **แผงควบคุมแอดมิน → ภาพรวม** (เมนูแรกสุด เป็นหน้าที่เปิดขึ้นมาให้อัตโนมัติ) หน้านี้อัปเดตข้อมูลมอนิเตอร์ฮาร์ดแวร์และสถานะระบบทุก 15 วินาทีโดยอัตโนมัติ

## 14.2 การ์ดสรุปตัวเลขด้านบน

| การ์ด | ความหมาย |
|---|---|
| ผู้ใช้งานทั้งหมด | จำนวนบัญชีทั้งหมดในระบบ |
| บทสนทนาทั้งหมด | จำนวนแชทที่เคยสร้างสะสม |
| คำขอวันนี้ / Token วันนี้ | ยอดการใช้งานรวมของทุกคนวันนี้ |
| คำขอทั้งหมด (สะสม) / Token ทั้งหมด (สะสม) | ยอดสะสมตั้งแต่เริ่มใช้ระบบ |

## 14.3 มอนิเตอร์ฮาร์ดแวร์

แถบแสดง % การใช้งาน **CPU, RAM, พื้นที่ดิสก์** ของเซิร์ฟเวอร์แบบเรียลไทม์ พร้อมแถบสีเตือน:

- 🟣 ม่วง = ปกติ
- 🟡 เหลือง = เริ่มสูง
- 🔴 แดง = สูงเกินเกณฑ์ (CPU/RAM เกิน 90%, ดิสก์เกิน 85%) — จะมีแบนเนอร์แจ้งเตือนสีแดงขึ้นด้านบนสุดของหน้าด้วย

## 14.4 กราฟแท่ง: การใช้งานตามช่วงเวลา

เลือกช่วงเวลาได้ 3 แบบ: **รายวัน / รายเดือน / รายปี** กราฟแสดงจำนวนคำขอและจำนวน token เปรียบเทียบกันในแต่ละช่วง ช่วยดูแนวโน้มการใช้งานว่าเพิ่มขึ้นหรือลดลง

## 14.5 กราฟวงกลม: สัดส่วนการใช้งานตามโหมด

แสดงสัดส่วนการใช้ token ระหว่าง **แชททั่วไป, เขียนโค้ด, และหัวข้อที่กำหนด** (จากระบบความรู้ AI ในบทที่ 16-17) ช่วยให้เห็นว่าผู้ใช้งานส่วนใหญ่ใช้ระบบไปทำอะไร

## 14.6 ผู้ใช้งานที่ใช้ token สูงสุดวันนี้

ตารางอันดับ Top 10 ผู้ใช้ที่ใช้ token มากที่สุดในวันนี้ — มีประโยชน์สำหรับตรวจสอบการใช้งานผิดปกติหรือวางแผนปรับโควตา

## 14.7 สรุปฐานข้อมูล

แสดงจำนวนแถวในแต่ละตารางของฐานข้อมูล (ผู้ใช้, บทสนทนา, ข้อความ, ประวัติการใช้งาน ฯลฯ) พร้อมขนาดไฟล์ฐานข้อมูลรวม เป็นตัวช่วยเบื้องต้นในการประเมินว่าถึงเวลาต้องดูแล/สำรองข้อมูลหรือยัง (รายละเอียดในบทที่ 19)

## 14.8 สถานะการเชื่อมต่อระบบ

รายการแสดงสถานะ **Backend API, ฐานข้อมูล (MySQL/MariaDB), Ollama (AI)** — ขึ้น `OK` สีเขียวถ้าเชื่อมต่อได้ปกติ หรือ `DOWN` สีแดงถ้ามีปัญหา ใช้เป็นจุดแรกในการวินิจฉัยเมื่อระบบมีปัญหา (ดูบทที่ 19)
