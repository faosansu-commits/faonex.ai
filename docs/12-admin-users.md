## 12.1 เข้าสู่แผงควบคุมแอดมิน

บัญชีที่มีสิทธิ์แอดมินจะเห็นปุ่ม **🛡 แผงควบคุมแอดมิน** ที่แถบด้านบนของหน้าแชท (บนมือถือแสดงเป็นไอคอน 🛡 แอดมิน) กดเพื่อเข้าสู่หน้าแผงควบคุม

หน้าแผงควบคุมมีเมนูด้านบน 5 ส่วน: **ภาพรวม, ผู้ใช้งาน, เนื้อหาที่ถูกแจ้งเตือน, API Key, ความรู้ AI** — บทนี้จะเน้นที่เมนู **ผู้ใช้งาน**

## 12.2 ดูรายชื่อผู้ใช้งานทั้งหมด

ไปที่เมนู **ผู้ใช้งาน** จะเห็นตารางแสดง:

| คอลัมน์ | ความหมาย |
|---|---|
| ผู้ใช้ | ชื่อผู้ใช้และชื่อที่แสดง |
| สิทธิ์ | ผู้ใช้งานทั่วไป / ผู้ดูแลระบบ |
| สถานะ | ใช้งานได้ / ถูกระงับ |
| วันนี้ (ครั้ง / token) | สถิติการใช้งานวันนี้ของแต่ละคน |
| ลิมิต/วัน | โควตาที่ตั้งไว้ (หรือค่าเริ่มต้นของระบบถ้าไม่ได้ตั้งเฉพาะ) |

## 12.3 ค้นหาผู้ใช้งาน

พิมพ์คำค้นในช่องค้นหาด้านบนตาราง ระบบจะกรองตามชื่อผู้ใช้หรือชื่อที่แสดงแบบเรียลไทม์

## 12.4 เพิ่มผู้ใช้งานใหม่ด้วยตนเอง

1. กดปุ่ม **+ เพิ่มผู้ใช้งาน**
2. กรอกข้อมูล: ชื่อผู้ใช้, ชื่อที่แสดง, รหัสผ่าน, สิทธิ์ (ผู้ใช้งานทั่วไป/ผู้ดูแลระบบ)
3. (ไม่บังคับ) กำหนดโควตาเฉพาะรายคน — ถ้าเว้นว่างจะใช้ค่าเริ่มต้นของระบบ
4. กดปุ่ม **บันทึก**

{: .warning }
> ระวังการพิมพ์ชื่อผู้ใช้ขณะที่คีย์บอร์ดค้างอยู่ในโหมดภาษาไทย เพราะอาจมีอักขระแปลกปลอมติดหน้าชื่อโดยไม่รู้ตัว (เช่น `ืnuch` แทนที่จะเป็น `nuch`) ทำให้ผู้ใช้เข้าสู่ระบบไม่ได้ ถ้าเจอปัญหานี้ให้แก้ไขชื่อผู้ใช้ในหน้าแก้ไขให้ตรงกับที่ตั้งใจไว้

## 12.5 แก้ไขข้อมูลผู้ใช้งาน

กดลิงก์ **แก้ไข** ที่แถวของผู้ใช้ที่ต้องการ ปรับได้ทั้งหมด:

- ชื่อที่แสดง
- สิทธิ์ (ผู้ใช้งานทั่วไป / ผู้ดูแลระบบ)
- สถานะเปิด-ปิดการใช้งานบัญชี
- โควตาจำนวนครั้ง/token ต่อวัน (เฉพาะรายคน)
- **ตั้งรหัสผ่านใหม่** (เว้นว่างไว้หากไม่ต้องการเปลี่ยน) — ใช้ช่วยเหลือผู้ใช้ที่ลืมรหัสผ่านได้โดยไม่ต้องรู้รหัสเดิม

## 12.6 ระงับ/ปลดระงับผู้ใช้งาน (บล็อก)

กดปุ่ม **ระงับ** ที่แถวของผู้ใช้เพื่อบล็อกไม่ให้เข้าสู่ระบบได้ทันที (ไม่ต้องเข้าไปหน้าแก้ไข) และกด **ปลดระงับ** เพื่อคืนสิทธิ์การใช้งาน

## 12.7 ลบผู้ใช้งาน

กดลิงก์ **ลบ** ที่แถวของผู้ใช้ — ระบบจะถามยืนยันก่อนเสมอ เนื่องจากการลบจะ**ลบประวัติบทสนทนาทั้งหมดของผู้ใช้คนนั้นไปด้วย** และไม่สามารถกู้คืนได้

{: .important }
> ระบบไม่อนุญาตให้ลบหรือลดสิทธิ์แอดมินคนสุดท้ายที่เหลืออยู่ในระบบ เพื่อป้องกันไม่ให้ไม่มีใครเข้าแผงควบคุมได้เลย ต้องมีแอดมินอย่างน้อย 1 คนเสมอ และไม่สามารถลบบัญชีของตัวเองได้

## 12.8 โควตาการใช้งานทำงานอย่างไร

- ทุกบัญชีมีโควตา **จำนวนครั้ง/วัน** และ **จำนวน token/วัน** ที่ใช้ได้ (รีเซ็ตทุกวันอัตโนมัติ)
- ค่าเริ่มต้นตั้งไว้ที่ไฟล์ `.env` (`APP_DEFAULT_DAILY_REQUEST_LIMIT`, `APP_DEFAULT_DAILY_TOKEN_LIMIT` — ดูบทที่ 5)
- แอดมินตั้งค่าทับเฉพาะรายบุคคลได้ในหน้าแก้ไขผู้ใช้ (ข้อ 12.5)
- เมื่อผู้ใช้ใช้ครบโควตา ระบบจะปฏิเสธคำขอแชทพร้อมข้อความแจ้งเตือน และ**ไม่เรียกใช้ AI เลย** (ประหยัดทรัพยากรเซิร์ฟเวอร์)
