## 15.1 สลับธีมมืด/สว่างและภาษา

เมนู ⚙️ ตั้งค่า (มุมขวาบน) ใช้ได้ทั้งผู้ใช้งานทั่วไปและแอดมิน ไม่ใช่เฉพาะแอดมินเท่านั้น:

- **ธีม**: มืด (ค่าเริ่มต้น) / สว่าง — ปรับสีตัวอักษร พื้นหลัง และโลโก้ให้เหมาะกับพื้นหลังโดยอัตโนมัติ
- **ภาษา**: ไทย (ค่าเริ่มต้น) / อังกฤษ — เปลี่ยนข้อความในเมนูและปุ่มต่างๆ ทั้งเว็บทันที

ค่าที่เลือกจะถูกบันทึกไว้ในเบราว์เซอร์ของแต่ละคน (ไม่กระทบผู้ใช้งานคนอื่น)

## 15.2 ระบบตรวจจับเนื้อหาที่อาจเป็นอันตราย

ไปที่ **แผงควบคุมแอดมิน → เนื้อหาที่ถูกแจ้งเตือน** เพื่อดูประวัติข้อความที่ระบบตรวจพบว่าอาจเข้าข่ายอันตราย/ผิดกฎหมาย

### หลักการทำงาน

ระบบใช้วิธี **ตรวจจับคำต้องห้าม (heuristic keyword matching)** — สแกนหาคำในรายการที่กำหนดไว้ล่วงหน้า เช่น คำเกี่ยวกับวัตถุระเบิด ยาเสพติด การแฮกระบบ การทำร้ายตนเอง เป็นต้น เพื่อความรวดเร็วและไม่เพิ่มภาระประมวลผล AI

{: .important }
> ระบบ**ไม่บล็อกข้อความ**ที่ตรวจพบ เพียงบันทึกไว้ให้แอดมินตรวจสอบภายหลังเท่านั้น (ป้องกันไม่ให้บล็อกผิดพลาดจนรบกวนการใช้งานจริง เช่น คำถามเชิงวิชาการที่บังเอิญมีคำในลิสต์)

### ข้อจำกัดที่ควรทราบ

- **ตรวจพลาดได้** หากผู้ใช้เลี่ยงคำ สะกดผิดตั้งใจ หรือใช้ภาษาอื่นที่ไม่อยู่ในลิสต์
- **แจ้งเตือนผิด (false positive) ได้** เช่น คำถามเชิงประวัติศาสตร์/วิทยาศาสตร์ที่บังเอิญมีคำในลิสต์
- ควรใช้เป็น**ข้อมูลประกอบการตรวจสอบ** ไม่ใช่การตัดสินขั้นสุดท้าย

### การดูรายละเอียดข้อความที่ถูกแจ้งเตือน

ตารางแสดง: ผู้ใช้ที่พิมพ์, ข้อความเต็ม, คำที่ตรงกับลิสต์ต้องห้าม, และเวลาที่เกิดขึ้น เรียงจากล่าสุดไปเก่าสุด

## 15.3 แก้ไข/เพิ่มคำในลิสต์ต้องห้าม (สำหรับนักพัฒนา)

รายการคำอยู่ในไฟล์ `backend/src/Config.php` ฟังก์ชัน `dangerousKeywords()` แก้ไขแล้วต้อง build backend ใหม่ด้วยคำสั่ง:

```bash
docker compose up -d --build backend
```
