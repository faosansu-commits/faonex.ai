## 2.1 ข้อกำหนดของเครื่อง (System Requirements)

| รายการ | ขั้นต่ำ | แนะนำ |
|---|---|---|
| RAM | 8 GB | 16 GB ขึ้นไป |
| พื้นที่ดิสก์ว่าง | 20 GB | 50 GB ขึ้นไป (ยิ่งดาวน์โหลดหลายโมเดลยิ่งใช้พื้นที่มาก) |
| ระบบปฏิบัติการ | Windows 10/11, macOS, หรือ Linux | Linux (สำหรับใช้งานจริงระยะยาว) |
| GPU | ไม่จำเป็น | มีก็ได้ (Ollama จะตอบเร็วขึ้นมากถ้ามี GPU) |
| อินเทอร์เน็ต | ใช้ตอนติดตั้งครั้งแรก (ดาวน์โหลดโมเดล/อิมเมจ) | ไม่จำเป็นหลังติดตั้งเสร็จ (ใช้งานได้แบบออฟไลน์) |

{: .note }
> ระบบนี้ถูกออกแบบมาให้รันได้แม้ไม่มี GPU (การ์ดจอสำหรับประมวลผล AI) แต่คำตอบจาก AI จะใช้เวลานานกว่าการมี GPU — ตั้งแต่ไม่กี่วินาทีไปจนถึงหลักนาทีต่อคำถาม ขึ้นกับสเปกเครื่องและความยาวของคำตอบ

## 2.2 ติดตั้ง Docker Desktop

FAONEX.AI รันผ่าน **Docker** ทั้งหมด จึงต้องติดตั้ง Docker ก่อนเป็นอันดับแรก

### ขั้นตอนสำหรับ Windows / macOS

1. ไปที่ [https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)
2. ดาวน์โหลดตัวติดตั้งสำหรับระบบปฏิบัติการของคุณ
3. เปิดไฟล์ติดตั้งแล้วทำตามขั้นตอนบนหน้าจอ (ใช้ค่าเริ่มต้นได้เลย)
4. รีสตาร์ทเครื่องหลังติดตั้งเสร็จ (ถ้าโปรแกรมแจ้งให้รีสตาร์ท)
5. เปิดโปรแกรม **Docker Desktop** แล้วรอจนสถานะขึ้นเป็น "Running" (ไอคอนวาฬที่มุมล่างขวาของหน้าจอ ไม่มีจุดสีแดง)

### ขั้นตอนสำหรับ Linux (Ubuntu/Debian)

```bash
# ติดตั้ง Docker Engine
curl -fsSL https://get.docker.com | sh

# เพิ่มผู้ใช้ปัจจุบันเข้ากลุ่ม docker (ไม่ต้องพิมพ์ sudo ทุกครั้ง)
sudo usermod -aG docker $USER

# ออกจากระบบแล้วเข้าใหม่ให้สิทธิ์กลุ่มมีผล จากนั้นทดสอบ
docker --version
docker compose version
```

## 2.3 ตรวจสอบว่า Docker พร้อมใช้งาน

เปิดโปรแกรม Terminal (Windows: PowerShell หรือ Git Bash / macOS-Linux: Terminal) แล้วรันคำสั่ง:

```bash
docker --version
docker compose version
```

ถ้าเห็นเลขเวอร์ชันแสดงขึ้นมาทั้งสองคำสั่ง (ไม่ใช่ error) แปลว่าพร้อมติดตั้ง FAONEX.AI แล้ว

{: .warning }
> ถ้ารันคำสั่งแล้วขึ้น error ว่าไม่รู้จักคำสั่ง `docker` ให้ตรวจสอบว่าเปิดโปรแกรม Docker Desktop ทิ้งไว้อยู่หรือยัง (สำหรับ Windows/macOS) หรือลองปิด-เปิด Terminal ใหม่หลังติดตั้งเสร็จ

## 2.4 (ทางเลือก) เตรียม Git

ถ้าต้องการดาวน์โหลดโค้ดผ่านคำสั่ง `git clone` ในบทถัดไป ให้ติดตั้ง Git ด้วย:

- **Windows**: ดาวน์โหลดจาก [https://git-scm.com/downloads](https://git-scm.com/downloads) (ติดตั้งแบบ Git Bash จะสะดวกที่สุด เพราะใช้คำสั่งแบบ Linux ได้)
- **macOS**: เปิด Terminal แล้วพิมพ์ `git --version` ระบบจะเสนอให้ติดตั้งอัตโนมัติถ้ายังไม่มี
- **Linux**: `sudo apt install git` (Ubuntu/Debian)

ถ้าไม่สะดวกใช้ Git สามารถกดปุ่ม "Download ZIP" จากหน้า GitHub repository แทนได้เช่นกัน (อธิบายในบทที่ 3)
