## ส่วนที่ 1: Public API สำหรับเซิร์ฟเวอร์ภายนอก

### 18.1 แนวคิด

นอกจาก `/api/*` ที่ใช้ในหน้าเว็บ (ต้องล็อกอินด้วย session) ระบบมี **public API แยกต่างหาก** ที่เซิร์ฟเวอร์อื่นเรียกใช้ได้โดยไม่ต้องผ่านเบราว์เซอร์ ยืนยันตัวตนด้วย **API key** แทน — เหมาะสำหรับเชื่อมต่อ FAONEX.AI เข้ากับระบบอื่นขององค์กร เช่น เว็บไซต์, แชทบอทในแอปอื่น, หรือระบบอัตโนมัติต่างๆ

### 18.2 สร้าง API Key ทีละขั้นตอน

1. ไปที่ **แผงควบคุมแอดมิน → API Key**
2. อ่านขั้นตอนสรุปที่แสดงอยู่บนหน้า (มีตัวอย่างคำสั่งเรียกใช้งานให้ดูประกอบ)
3. กรอกชื่อ (label) เพื่อระบุว่า key นี้ใช้กับระบบ/เซิร์ฟเวอร์ไหน เช่น "เว็บไซต์โรงเรียน"
4. กดปุ่ม **+ สร้าง API key**
5. **คัดลอก key ที่แสดงขึ้นมาทันทีเก็บไว้ในที่ปลอดภัย** — ระบบจะไม่แสดง key เต็มให้เห็นอีกหลังจากนี้ (เห็นได้แค่บางส่วนในตารางเพื่อยืนยันตัวตน)

{: .important }
> ถ้าลืมคัดลอก key ไว้ ต้องยกเลิก key เดิมแล้วสร้างใหม่เท่านั้น ไม่สามารถดู key เต็มซ้ำได้ในภายหลัง (เพื่อความปลอดภัย ระบบเก็บเฉพาะค่า hash ของ key ไว้ในฐานข้อมูล ไม่ได้เก็บ key จริง)

### 18.3 เรียกใช้งานจากเซิร์ฟเวอร์ภายนอก

ส่ง key ไปกับ header `Authorization: Bearer <key>`:

```bash
curl -X POST https://<โดเมนหรือไอพีของคุณ>:8095/api/v1/chat \
  -H "Authorization: Bearer fao_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"message": "สวัสดี", "mode": "chat"}'
```

### 18.4 Endpoint ที่มีให้ใช้งาน

| Method | Path | คำอธิบาย |
|---|---|---|
| POST | `/api/v1/chat` | ส่งข้อความแชท รับพารามิเตอร์ `message`, `history` (ถ้าต้องการบริบทหลายรอบ), `mode`, `model`, `images` |
| GET | `/api/v1/models` | รายชื่อโมเดลแชทที่เลือกได้ พร้อมสถานะติดตั้ง |

### 18.5 ข้อควรทราบ

- `/api/v1/*` เป็น **stateless** — ไม่บันทึกประวัติบทสนทนาให้อัตโนมัติ ผู้เรียกต้องส่ง `history` เองถ้าต้องการให้ AI จำบริบทของการสนทนาหลายรอบ
- มีโควตารายวันร่วมกันทุก API key (ใช้ค่าเดียวกับผู้ใช้ทั่วไปใน `.env`) เกินแล้วจะได้รหัสตอบกลับ `429`
- ยกเลิก API key ได้ทุกเมื่อที่หน้าเดียวกัน โดยกดปุ่ม **ยกเลิกใช้งาน**

## ส่วนที่ 2: ฐานข้อมูล MySQL/MariaDB และ phpMyAdmin

### 18.6 เข้าใช้งาน phpMyAdmin

เปิดเบราว์เซอร์ไปที่ `http://<เซิร์ฟเวอร์>:8096` แล้วล็อกอินด้วยค่าที่ตั้งไว้ใน `.env`:

| ช่อง | ค่า |
|---|---|
| Server | `mysql` (กรอกอัตโนมัติอยู่แล้ว) |
| Username | ตามค่า `DB_USER` |
| Password | ตามค่า `DB_PASSWORD` |

หรือใช้ `root` / ค่า `DB_ROOT_PASSWORD` สำหรับสิทธิ์เต็ม

### 18.7 ตารางข้อมูลหลักในระบบ

| ตาราง | เก็บอะไร |
|---|---|
| `users` | บัญชีผู้ใช้งานทั้งหมด |
| `conversations` | รายการบทสนทนา |
| `messages` | ข้อความในแต่ละบทสนทนา |
| `usage_log` | ประวัติการใช้งาน (สำหรับสถิติ) |
| `flags` | ข้อความที่ถูกระบบตรวจจับว่าน่าสงสัย |
| `api_keys` | API key ที่แอดมินออกให้ |
| `knowledge_topics`, `knowledge_documents`, `knowledge_chunks` | ข้อมูลระบบความรู้ AI (RAG + Rule) |

{: .warning }
> การแก้ไข/ลบข้อมูลโดยตรงผ่าน phpMyAdmin เป็นการเปลี่ยนแปลงที่**ย้อนกลับไม่ได้** ควรใช้ความระมัดระวังสูงสุด และควรสำรองข้อมูลก่อนแก้ไขสิ่งใดที่ไม่แน่ใจเสมอ (ดูวิธีสำรองข้อมูลในบทที่ 19)
