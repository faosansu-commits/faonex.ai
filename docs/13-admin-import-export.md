## สารบัญในบทนี้
{: .no_toc .text-delta }

1. TOC

บทนี้เหมาะสำหรับแอดมินที่ต้องเพิ่มผู้ใช้งานจำนวนมากในครั้งเดียว (เช่น รายชื่อนักเรียนทั้งชั้นเรียน) หรือต้องการรายงานสรุปเป็นไฟล์เพื่อเก็บ/พิมพ์

## 13.1 นำเข้าผู้ใช้งานเป็นชุดด้วยไฟล์ Excel

1. ไปที่ **แผงควบคุมแอดมิน → ผู้ใช้งาน**
2. กดปุ่ม **⬆ นำเข้า Excel**
3. เตรียมไฟล์ `.xlsx` โดยแถวแรกเป็นหัวคอลัมน์ตามนี้:

| username | password | displayName | role | dailyRequestLimit | dailyTokenLimit |
|---|---|---|---|---|---|
| student001 | Passw0rd! | เด็กชายสมชาย ใจดี | user | | |
| teacher01 | Teach1234 | ครูสมหญิง | admin | 200 | 50000 |

- **username, password** จำเป็นต้องกรอก
- **displayName** ถ้าเว้นว่างจะใช้ username แทน
- **role** ใส่ `admin` หรือ `user` (เว้นว่าง = `user`)
- **dailyRequestLimit, dailyTokenLimit** เว้นว่างได้ถ้าต้องการใช้ค่าเริ่มต้นของระบบ

4. กดเลือกไฟล์ ระบบจะประมวลผลและแจ้งผลลัพธ์ทันที: จำนวนที่นำเข้าสำเร็จ และรายการที่ผิดพลาดพร้อมระบุว่าแถวที่เท่าไหร่มีปัญหาอะไร (เช่น ชื่อผู้ใช้ซ้ำ, รหัสผ่านสั้นเกินไป)

{: .note }
> แถวที่ผิดพลาดจะถูกข้ามไป ไม่กระทบแถวอื่นที่ถูกต้อง — สามารถแก้ไฟล์เฉพาะแถวที่ error แล้วนำเข้าซ้ำเฉพาะส่วนนั้นได้

## 13.2 ส่งออกรายชื่อผู้ใช้งานทั้งหมดเป็น Excel

กดปุ่ม **⬇ ส่งออก Excel** ที่หน้าจัดการผู้ใช้งาน ระบบจะดาวน์โหลดไฟล์ `.xlsx` ที่มีรายชื่อผู้ใช้งานทั้งหมดในระบบพร้อมสถิติการใช้งานทันที เหมาะสำหรับนำไปวิเคราะห์ต่อหรือเก็บเป็นหลักฐาน

## 13.3 ส่งออกรายงานผู้ใช้รายคนเป็น PDF

ที่แถวของผู้ใช้แต่ละคนในตาราง กดลิงก์ **PDF** เพื่อดาวน์โหลดรายงานสรุปของผู้ใช้คนนั้น ประกอบด้วย:

- ข้อมูลบัญชี (ชื่อผู้ใช้, สิทธิ์, สถานะ)
- สถิติการใช้งานวันนี้
- กราฟ/ตารางการใช้งานย้อนหลัง 30 วัน

รายงาน PDF รองรับ**ภาษาไทยเต็มรูปแบบ** (ใช้ฟอนต์ Sarabun ที่ฝังไว้ในระบบ) พิมพ์ออกมาอ่านได้ปกติไม่มีปัญหาตัวอักษรเพี้ยน
