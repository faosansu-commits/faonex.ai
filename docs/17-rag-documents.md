หัวข้อหนึ่งสามารถใส่เนื้อหาได้ **2 วิธี** ใช้ร่วมกันในหัวข้อเดียวกันได้ ไม่จำเป็นต้องเลือกอย่างใดอย่างหนึ่ง

## 17.1 วิธีที่ 1: พิมพ์คำตอบเอง (ไม่ต้องมีไฟล์ PDF)

1. ที่หน้ารายการหัวข้อ กดปุ่ม **▼ จัดการเนื้อหา** ที่แถวของหัวข้อที่ต้องการ (แผงจะขยายออกมาในหน้าเดียวกันทันที)
2. ในช่อง **เพิ่มคำตอบด้วยตัวเอง**:
   - **ชื่อรายการ** (ไม่บังคับ) เช่น "ขั้นตอนการสมัครเรียน"
   - **เนื้อหาคำตอบ** พิมพ์รายละเอียดคำตอบแบบเต็ม
3. กดปุ่ม **บันทึกคำตอบ**
4. ระบบจะประมวลผล (สร้าง embedding) สักครู่แล้วแสดงในรายการเนื้อหาด้านล่างทันที (มีไอคอน ✏️ กำกับว่าเป็นเนื้อหาที่พิมพ์เอง)

### ตัวอย่างการเขียนคำตอบที่ดี

```
โรงเรียนเปิดรับสมัครนักเรียนใหม่ทุกปีการศึกษา ระหว่างวันที่ 1-31 มีนาคม
เอกสารที่ต้องใช้ในการสมัครเรียน ได้แก่ สำเนาบัตรประชาชนนักเรียน
สำเนาทะเบียนบ้าน และรูปถ่ายขนาด 1 นิ้ว จำนวน 2 รูป
ค่าธรรมเนียมแรกเข้า 500 บาท ชำระที่ฝ่ายการเงินของโรงเรียนในวันสมัคร
สอบถามเพิ่มเติมได้ที่ฝ่ายทะเบียน โทร 02-123-4567
```

## 17.2 วิธีที่ 2: อัปโหลดเอกสาร PDF (ไม่บังคับ)

1. ในแผง "จัดการเนื้อหา" เดียวกัน มองหาส่วน **หรืออัปโหลดเอกสาร PDF เพิ่มเติม (ไม่บังคับ)**
2. กดปุ่ม **⬆ อัปโหลด PDF** แล้วเลือกไฟล์
3. ระบบจะดึงข้อความจากไฟล์ แบ่งเป็นส่วนย่อย และสร้าง embedding ให้อัตโนมัติ (ขึ้นข้อความ "กำลังประมวลผลไฟล์...")
4. เมื่อเสร็จ ไฟล์จะปรากฏในรายการเนื้อหา (มีไอคอน 📄 กำกับว่าเป็นไฟล์ PDF)

{: .warning }
> รองรับเฉพาะไฟล์ PDF ที่**มีเลเยอร์ข้อความจริง** (พิมพ์จากคอมพิวเตอร์) ไม่รองรับไฟล์ที่เป็นภาพสแกนล้วนๆ ที่ไม่มีข้อความให้ดึงออกมาได้

## 17.3 ดาวน์โหลดฟอร์มตัวอย่างการเขียนคำตอบ

ที่หน้ารายการหัวข้อหลัก กดปุ่ม **⬇ ดาวน์โหลดฟอร์มตัวอย่าง (Word)** จะได้ไฟล์ `.docx` ที่มีคำแนะนำและตัวอย่างการเขียนคำตอบที่ดี ใช้เตรียมเนื้อหาก่อนพิมพ์ลงระบบโดยตรง หรือก่อนบันทึกเป็น PDF เพื่ออัปโหลดภายหลังก็ได้

## 17.4 หลักการเขียนคำตอบให้ AI ใช้งานได้ดี

- เขียนให้ชัดเจน ตรงประเด็น ใช้ประโยคสมบูรณ์
- แยกแต่ละหัวข้อย่อยเป็นคนละย่อหน้า เพื่อให้ระบบค้นหาส่วนที่เกี่ยวข้องได้แม่นยำ
- ระบุข้อมูลข้อเท็จจริงให้ครบ (วันที่ จำนวนเงิน เบอร์โทร เงื่อนไข) ไม่ปล่อยให้ AI ต้องเดา
- แต่ละย่อหน้าควรอ่านเข้าใจได้ในตัวเอง โดยไม่ต้องอ้างอิงย่อหน้าอื่นประกอบ
- หลีกเลี่ยงข้อมูลที่ขัดแย้งกันเองในหัวข้อเดียวกัน
- อัปเดตเนื้อหาให้ตรงกับความเป็นจริงเสมอ ลบ/แก้ไขเมื่อข้อมูลเปลี่ยน

## 17.5 ลบเนื้อหา

กดปุ่ม **ลบ** ที่แถวของรายการเนื้อหา (ทั้งแบบพิมพ์เองและ PDF) ในแผง "จัดการเนื้อหา" — ลบได้ทีละรายการโดยไม่กระทบเนื้อหาอื่นในหัวข้อเดียวกัน

## 17.6 ทดสอบผลลัพธ์จริง

หลังใส่เนื้อหาเสร็จ ให้ไปทดสอบที่**หน้าแชทจริง**:

1. เปิดแชทใหม่
2. พิมพ์คำถามที่ตรงกับคำค้นของหัวข้อที่สร้างไว้ เช่น "สมัครเรียนต้องใช้เอกสารอะไรบ้าง"
3. สังเกตว่า AI ตอบตรงกับเนื้อหาที่ใส่ไว้หรือไม่
4. ลองถามคำถามที่ตรงคำค้นแต่**ไม่มีข้อมูลรองรับ** (เช่น ถามเรื่องผ่อนชำระถ้าไม่ได้ใส่ข้อมูลนี้ไว้) เพื่อดูว่าระบบตอบด้วยข้อความสำรองถูกต้องหรือไม่

## 17.7 ปรับความเข้มงวดของการค้นหา (สำหรับนักพัฒนา)

ถ้า AI ตอบด้วยข้อความสำรองบ่อยเกินไปทั้งที่มีข้อมูลรองรับอยู่ หรือตรงกันข้าม ตอบข้อมูลที่ไม่ค่อยเกี่ยวข้องนัก สามารถปรับค่าใน `.env` ได้ (ดูบทที่ 5):

```env
APP_RAG_TOP_K=4                    # จำนวนส่วนเนื้อหาที่ดึงมาอ้างอิงต่อคำถาม
APP_RAG_SIMILARITY_THRESHOLD=0.35  # ค่าความใกล้เคียงขั้นต่ำ (0-1) ยิ่งสูงยิ่งเข้มงวด
```
